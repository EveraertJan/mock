# mock

A modular tool to prototype physical interactions. New elements will be added if necessary.
So far, the following blocks are in development;

* a 5v power block
* ADA: a module containing space for 4 sensors (buttons, DHT, microphone, LDR,...)
* Ernst: A module containing a speaker able to play a file on trigger
* Frank: A stepper motor and attachment plate
* Harvey: A power outlet
* Oleg: A LED light
* Regi: A distance sensor
* Will: A series of 4 LDRS for simple movement experiments

On the todo list:
* a gyroscopic one
